CSS Selectors

Answer the following questions:

  • List out the different ways to select an item.
    • → We can use inline selection (ID and Class) and tag selection (Span and Div).
  • What is the difference between an ID and a Class?
    • → ID is unique for one tag only but Class is unique but good to reuse it.
  • What is the difference between a SPAN tag and a DIV tag?
    • → SPAN tag can pick a certain letters, words, or passages without giving a new line break. Div does the same but give a line break.
  • What is the difference between a DIV tag and a HEADER, MAIN, or FOOTER?
    • → DIV tag is used without meaning, it is used just for layout purpose, to beautify the webpage
  • What are the different ways to select a color?
    • → For selecting color, we can search using the name of the color, HEX code, RGB, or HSL.
