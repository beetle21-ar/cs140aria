Why is the viewport meta tag important?

Why the Viewport Meta Tag Matters Without the viewport meta tag, mobile browsers assume your website is designed for a desktop screen. They will render the page at a typical desktop width (usually around 980px) and zoom out to fit it on the mobile device, resulting in tiny, unreadable text and links that are too small to tap. Adding meta name="viewport" content="width=device-width, initial-scale=1.0" forces the browser to match the screen's actual width and scale the layout appropriately, which is the foundation of responsive web design.

How can you adjust the CSS for printing?

You can target printers and PDF exports directly using the @media print query in your stylesheet. Any CSS rules placed inside this block will override your standard styles only when the document is printed. Common adjustments include:

  • Hiding UI elements: Using display: none; on navigation bars, sidebars, video players, and interactive buttons that serve no purpose on paper.
  • Optimizing for ink: Changing text to black, removing heavy background colors, and swapping to high-contrast styles to save printer ink.

When would you want to adjust the CSS for printing?

You should implement a print stylesheet whenever your website contains information a user might want to reference offline, file away, or hand to someone else. Standard use cases include:

  • Commerce and Finance: Invoices, receipts, and order confirmations.
  • Travel and Events: Boarding passes, itineraries, and event tickets.
  • Information and Utility: Recipes, long-form articles, sheet music, resumes, and technical documentation.
