This box demonstrates custom padding, bottom-only border, and 4 different margins.
  1. What is the difference between block tags and inline tags?
    Block tags usually start on a new line and fill the available width. Inline tags stay on the same line as other content and only use the space they need.
  2. What is the margin, border, and padding?
    Margin is the space outside the border, and padding is the space between the content and the border. The border is a line that surrounds the content and padding.
  3. What are units of measurement you can use in CSS?
    You can use units such as px, em, rem, %, vw, and vh in CSS. Pixels have a fixed size, while the other units depend on a font size, an element's size, or the browser window.
  4. When would you use a figure tag?
    Use a figure tag to group content such as a picture, chart, or code example that makes sense on its own. You can add a figcaption tag inside it to describe the content.
