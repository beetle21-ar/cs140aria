What are the positives and negatives of hosting your videos on YouTube?

Positives: Saves storage and easy to use, high compatibility and many features from youtube to use.
Negatives: YouTube can show ads, shows recommendation videos, and youtube has right to rule how we will use the video.

What is the most useful thing you can do with a transform?

CSS transform lets you move (translate), resize (scale), rotate, or skew elements visually without affecting the document flow.

What is the difference between a transform and a transition?

transform is a CSS property that changes an element's shape, size, rotation, or position.
transition controls how smoothly and over what duration a CSS property changes from one state to another.
