Questions Part 1

The form tag has an "action" attribute. What does it do?

→ It is to bring the user to the target html based on their form data that has been filled. the user will not be able to go the the target html if the user does not fill the form completely as prompted.

The form tag has a "method" attribute. What does it do?

→ It is to choose which method to send the form of data to the server.

What is the difference between a "POST" and a "GET"?

→ If we are changing or adding data, we use post, if we want to use search engine, we want to show an article, etc, we use get.

How do you fill in a form control with a pre-set value, and how is that different from a placeholder? Answer for each of these: text box, textarea, select box, checkbox, and radio button.

→ Pre-set value is an actual option that user can choose instead of inputting a data. User must change the value so that the preset will not be chosen.

A placeholder is a hint that helps user to know what to input
