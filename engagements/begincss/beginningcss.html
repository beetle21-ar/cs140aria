Explain the difference between inline, embedded, and external CSS.
→ Inline CSS
For its location, it is inside a specific HTML element tag. It only affects the single element. highest priority.

→ Embedded CSS
For its location, it is inside a style tag. It affects the entire single page. medium priority.

→ External CSS
For its location, it is a separate .css file. it affects multiple pages. lowest priority.

Explain why you should only use external CSS.
→ Some items to pay attention with, such as to make html file stays clean, to write once and can be applied to everywhere, and looks cleaner.

What is a selector used for?

→ A CSS selector is used to target specific HTML elements so you can apply styles (like colors, spacing, and fonts) to them.
