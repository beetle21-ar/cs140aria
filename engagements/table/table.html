Questions part 2

Why don't we use the border attribute?

The border attribute is outdated attribute, now we use css to style the html.

What is the easiest way to color every other row a different color?

The easiest way is using the CSS pseudo-class :nth-child(even) (or :nth-child(odd)).

What does the value in the parentheses of your structural pseudo-class mean? Give one other value you could use and which rows it would select.

It is for choosing which row or column you want to give effect to. I use tr:nth-child(even), it means that I use even number to give different color from the odd rows. Another value is odd, which would select the 1st, 3rd, 5th, and all other odd-numbered rows.
