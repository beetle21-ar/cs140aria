Questions

Answer the following questions:

  1. What kind of photos are good to encode using JPEG?
    → Real photos from a camera or phone, like people, nature, or landscapes. They have a lot of colors and JPEG makes the file small.
  2. What kind of photos are good to encode using GIF?
    → Simple pictures with not many colors (only 256 colors), like logos, icons, cartoons, and small animations.
  3. What is unique about the PNG format?
    → PNG can have a transparent background and it does not lose quality when saved (lossless). Good for logos and screenshots.
  4. How do you resize your photo to the size it should be displayed?
    → Open the photo in photo editing software like Photoshop, GIMP, or Paint, change the image size (width and height in pixels) to the size on the webpage, then save it again.
  5. Why should you resize photos using photo editing software instead of resizing it using CSS?
    → CSS only makes the photo look smaller, but the browser still downloads the big file. So the page loads slow. Resizing with software makes the file smaller and the page loads faster.
