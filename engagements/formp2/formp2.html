What is JavaScript? How did it get its name?
JavaScript is a programming language that runs in web browsers to make websites interactive. It was created at Netscape and was first called LiveScript. Later, the company changed the name to JavaScript as a marketing decision because Java was very popular at that time, even though the two languages are different.

What are the two ways you can run JavaScript?
1. Inside a web browser
2. Outside the browser using Node.js

What is jQuery? Is it still popular today?
jQuery is an older JS library that simplified DOM manipulation and cross-browser code, and that its popularity has declined because modern built-in JS and newer tools replaced it.

What is the most popular front-end js library today?
React
