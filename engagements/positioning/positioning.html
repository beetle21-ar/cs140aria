Questions To Be Answered

  • What is normal flow in HTML?

    Normal flow is the default way HTML elements appear on a page. They follow the order in the HTML, with block elements starting on a new line.

  • What does float do? Why do you need to clear the float?

    Float moves an element to the left or right, and nearby text can wrap around it. Clear tells the next element to move below the float, so other content does not stay beside it.

  • What do absolute, fixed, and relative do?

    Relative moves an element from its normal place, but it keeps its space in the page. Absolute places an element in relation to its nearest positioned parent and removes it from normal flow. Fixed keeps an element in the same place on the screen when you scroll.

  • How can you make nice navigation buttons for mobile devices?

    Use clear labels, large text, and enough space so people can tap the buttons easily. On a small screen, you can put the buttons in a vertical list.
