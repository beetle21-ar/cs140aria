What is AJAX?

AJAX stands for Asynchronous JavaScript and XML. AJAX is a set of web development techniques used to let a web page communicate with a server in the background and build faster and more interactive web applications.

Why do you put your JS Code in a separate file?

It is to separate the structure of the webpage and the behavior of the webpage, make the code easier to maintain. Same as CSS, JS can be reused across many HTMLs.

How do you use the inspector (DevTools) to debug your JavaScript? How do you find the line number of an error?

DevTools is used to see any error through the Console tab. When JavaScript has a syntax or runtime error, a red error message appears in the Console tab.
