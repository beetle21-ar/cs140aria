When should you use a background image, and when should you use the IMG tag?
Use an img tag when the image is meaningful content, such as a pipeline photo or portrait. It supports alt text, accessibility, image dimensions, and search engines.
Use a CSS background-image when the image is decorative or part of the page’s design, such as a texture, pattern, or decorative botanical image. Background images should not contain important information because screen readers generally ignore them.
