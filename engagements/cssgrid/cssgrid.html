According to the instructor, what is the main difference between CSS Grid and CSS Flex?

CSS Grid is a two-dimensional layout system that handles both rows and columns, the children follow the parents container, whereas CSS Flex is a one-dimensional layout system designed to arrange elements in a single direction—either as a row or a column, the parents container follows the need of the children.

Who decides where a child goes on the page: the child or its parent? Explain using your three-column layout.

The parent decides. In my layout the .parent container has display: grid with three 200px columns, so it places each card (BOX A to F) into a column. The cards do not place themselves. BOX C is a child of the container, but it is also a parent: it holds my .parents div, and that div uses its own grid to place its five children. The headings and paragraphs inside each card just use normal flow, because the card has no layout of its own.
