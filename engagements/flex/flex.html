2. Why do you need to have an accessible website? What does that mean?

An accessible website is a digital space designed so everyone—including people with disabilities—can use it seamlessly. Think of it like adding wheelchair ramps, braille signs, and automatic doors to a physical building, but doing so within the code of the internet.

To make a website accessible, designers and developers follow the Web Content Accessibility Guidelines (WCAG), which serve as the global industry benchmark. Accessibility boils down to four main ideas, often called the "POUR" principles: Perceiveable, operable, understandable, and robust.
