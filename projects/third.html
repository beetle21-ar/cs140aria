Internet and Web Definitions

  • Internet

    • Internet is a huge network that connects connected devices to enable them to communicate.

  • Web

    • Web is a system where documents and resources can communicate via internet.

  • How are the Internet and Web different?

    • The internet is the hardwares that are communicating and making network, but web is collection of information that run on that network.

  • ASCII and Unicode

    • ASCII and Unicode are standard encoding systems where computer can store numbers, texts, or symbols by assigning numbers to them.

  • What is UTF-8

    • UTF-8 is a variable-length encoding system that translates a character into a binary code.

  • URL

    • URL stands for Uniform Resource Locator, means the unique address that is used to find specific file or webpage.

  • Domain Name

    • Domain Name is the web address that represents the brand, project, or extension. Domain Name has TLD(Top-Level Domain) and SLD(Second-Level Domain).

  • HTTP

    • HTTP(Hypertext Transfer Protocol) is the foundational set of rules that is used by computers to communicate and share data in World Wide Web. It works through client request and server response.

  • HTTPS

    • HTTPS(Hypertext Transfer Protocol Secure) is the secure and encrypted version of HTTP. It works by scrambling the data so only our browser and the server that can read it.

  • IP Address

    • IP Adress(Internet Protocol Address) is a unique numerical label that is assigned to a device when it connects to a network. It gives the device an identity and shows the route for data packets to the correct destination.

  • DNS

    • DNS(Domain Name System) is like a phonebook of the internet that reads a human-readable website names as a numerical IP addresses.It helps the machine to get the IP address connected to the human-readable domain name when we input it in URL.

  • W3C Recommendations

    • W3C(World Wide Web Consortium) is the main international group that makes rules and guides for the internet. The rules and guides meant for helping us to use web tools easier, safer, and more private. Currently, we have HTML and CSS as the web languages to use, JSON and XML as the data formats, and APIs that standardize how scripts interact with web documents.

  • XML, XHTML, HTML, HTML5

    • XML(Extensible Markup Language) is a text-based format data that designed to store, organize, and transport data between the computer systems. Focus on data interchange.

    XHTML(EXtensible HyperText Markup Language) is a combination of HTML and XML. It looks very similar to HTML but stricter. Often being said that need to follow the rules exactly and more precise way to write a web code.

    HTML(Hypertext Markup Language) is the standard language for a document to be displayed in a web browser.

    HTML5 is the fifth version of HTML. It has new tags, new built-in features, offline storage, and many new advantages.
